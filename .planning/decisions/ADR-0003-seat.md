# ADR-003: 실시간 좌석 조회 — 결정적 난수 시뮬레이션으로 대체

| 항목 | 내용 |
|---|---|
| **상태** | Accepted |
| **날짜** | 2026-05 |

## 배경

버스 예약 앱의 핵심 기능 중 하나는 실시간 좌석 현황 조회이다.
그러나 아래와 같은 이유로 실제 실시간 좌석 데이터를 가져오는 것이 불가능하다.

### 실시간 좌석 조회가 불가능한 이유

| 이유 | 설명 |
|---|---|
| **독점 유료 서비스** | 시외버스 실시간 좌석 API는 코버스(KOBUS)·금호고속 등 민간 업체가 독점 운영하며, 외부에 공개하지 않음 |
| **공공 API 미지원** | 공공데이터포털(data.go.kr)의 시외버스 API는 노선·시간표·요금 정보만 제공하고, 실시간 잔여 좌석 데이터는 제공하지 않음 |
| **B2B 계약 필요** | 실시간 좌석 연동은 터미널 사업자와 별도 B2B 계약 후 전용 API 키를 발급받아야 하며, 개인 개발자·학생 프로젝트에는 접근 불가 |
| **비용 문제** | 일부 민간 API 중개 서비스가 존재하나 월 수십만 원 이상의 유료 구독 모델로 운영됨 |

## 결정

**결정적 난수(Deterministic Random) 기반 좌석 시뮬레이션**을 사용한다.

- 버스 ID + 날짜를 seed로 `Random(seed)` 생성
- 동일한 버스·날짜는 항상 동일한 좌석 배치를 반환 (앱 재실행 후에도 일관성 유지)
- 탑승률 40% 기준으로 occupied / available 랜덤 배분

```dart
List<SeatStatus> generateSeats(String busId, String date) {
  final seed = int.parse(busId.replaceAll(RegExp(r'\D'), ''))
             + date.hashCode;
  final rng = Random(seed);
  return List.generate(28, (_) =>
    rng.nextDouble() < 0.4
      ? SeatStatus.occupied
      : SeatStatus.available);
}
```

## 대안 검토

| 대안 | 검토 결과 |
|---|---|
| 실시간 API 연동 | 불가 — 공개 API 없음, B2B 계약 필요 |
| 매번 순수 랜덤 | 재실행마다 좌석 배치가 달라져 사용자 혼란 유발 |
| 전부 빈 좌석 고정 | 비현실적, 시연 시 설득력 부족 |
| 전부 매진 고정 | 예약 흐름 시연 불가 |

## 결과

| 긍정 | 부정 |
|---|---|
| API 없이 현실적인 좌석 UI 시연 가능 | 실제 잔여 좌석과 다름 |
| 동일 버스·날짜는 항상 일관된 좌석 표시 | 실 서비스 전환 시 이 함수만 교체 필요 |
| 구현 단순 (seed 기반 1개 함수) | — |

> 💡 **실 서비스 전환 시**: `generateSeats()` 함수를 실시간 API 호출로 교체하면 나머지 UI는 그대로 동작하는 구조로 설계됨.
