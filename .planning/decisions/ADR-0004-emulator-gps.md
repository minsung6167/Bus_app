# ADR-004: 에뮬레이터 GPS 한계 — 수동 위치 설정으로 대응

| 항목 | 내용 |
|---|---|
| **상태** | Accepted |
| **날짜** | 2026-06 |

## 배경

버스 앱의 지도 화면에서 현재 위치 표시, 수면 모드의 목적지 도달 감지 기능은 GPS 위치 데이터에 의존한다.
개발 및 시연 환경이 Android 에뮬레이터인 상황에서 아래와 같은 제약이 존재한다.

### 에뮬레이터에서 실시간 GPS가 불가능한 이유

| 이유 | 설명 |
|---|---|
| **GPS 칩 부재** | Android 에뮬레이터는 가상 머신이므로 실제 GPS 수신 칩이 없음 |
| **위성 신호 없음** | 물리적 위성 신호를 수신하는 하드웨어가 존재하지 않아 실시간 위치 변화 추적 불가 |
| **위치 고정** | 에뮬레이터를 재시작하면 위치가 기본값(주로 미국 마운틴뷰 등)으로 초기화됨 |

## 결정

**Android Studio Extended Controls의 Location 탭을 통해 수동으로 위치를 설정**한다.

```
에뮬레이터 우측 ⋮ 버튼 → Location 탭
→ Latitude / Longitude 입력 → Send 버튼
```

예시 좌표 (서울):

| 항목 | 값 |
|---|---|
| Latitude | 37.5665 |
| Longitude | 126.9780 |

## 대안 검토

| 대안 | 검토 결과 |
|---|---|
| 실기기(Android) 테스트 | 가장 정확하지만 USB 디버깅 설정 필요, 기기 의존성 있음 |
| 에뮬레이터 `-dns-server` 플래그 + GPS mock | DNS는 해결되나 GPS 실시간 추적은 여전히 불가 |
| 위치 하드코딩 (서울 고정) | GPS 기능 자체를 무력화하여 실제 동작 흐름 시연 불가 |
| **수동 위치 설정 (채택)** | 에뮬레이터 내장 기능으로 간단히 원하는 좌표 지정 가능 |

## 결과

| 긍정 | 부정 |
|---|---|
| 추가 도구 없이 에뮬레이터만으로 GPS 기능 시연 가능 | 이동 시뮬레이션(경로 추적)은 불가 |
| 원하는 지점을 자유롭게 지정해 수면 모드 알림 테스트 가능 | 매 세션마다 수동으로 좌표를 입력해야 함 |
| 실기기 없이 개발 환경만으로 위치 관련 UI 검증 가능 | 실시간 위치 추적은 실기기에서만 검증 가능 |
