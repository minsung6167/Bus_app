# ADR-002: 버스 목록 정렬 기준 — 출발 시간순 고정

| 항목 | 내용 |
|---|---|
| **상태** | Accepted |
| **날짜** | 2025-02 |

## 배경

버스 목록을 사용자에게 보여줄 때 정렬 기준이 필요했다.
후보: 출발 시간순, 가격순, 잔여 좌석순, 사용자 선택 정렬.

## 결정

**출발 시간 오름차순으로 고정**한다.

- 사용자가 버스 선택 시 가장 먼저 확인하는 정보는 "몇 시에 출발하나"임
- 출발 시간순 정렬이 시각적으로 가장 직관적이고 예측 가능함
- 정렬 옵션 UI 추가 시 화면이 복잡해지고 졸업 작품 범위를 초과함

## 결과

| 긍정 | 부정 |
|---|---|
| 사용자가 시간대별로 한눈에 파악 가능 | 가격순·잔여석순 정렬 불가 |
| 구현 단순 (추가 UI 불필요) | 사용자 정렬 선호도 반영 불가 |
