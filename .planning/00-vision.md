# 00. 비전 & 목표

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 시외버스 예약 앱 |
| 성격 | 졸업 작품 |
| 플랫폼 | Flutter (Android + iOS) |
| 언어 지원 | 한국어 / 영어 / 중국어 / 일본어 |
| 데이터 | 공공 API (실제 노선) |
| 결제 | UI 시뮬레이션 (실제 PG 미연동) |

---

## 비전

> **"누구나, 어디서든, 쉽게 시외버스를 예약할 수 있는 앱"**

내국인은 물론 한국을 방문한 외국인 관광객도 언어 장벽 없이
시외버스 노선을 검색하고 좌석을 예약할 수 있는 모바일 앱을 구현한다.

---

## 목표

### 학습 목표
- Flutter + Dart 기반 크로스 플랫폼 앱 개발 역량 증명
- Provider 패턴을 활용한 상태 관리 구조 설계
- 공공 API 연동 및 비동기 데이터 처리
- 다국어(i18n) 지원 구조 설계 및 구현

### 기능 목표
- 출발지/도착지 선택 → 버스 목록 조회 → 좌석 선택 → 예약 확인 흐름 완성
- 한/영/중/일 4개 언어 전환 기능
- 이메일 + 소셜(카카오/네이버) 로그인 지원
- 즐겨찾기 터미널로 반복 예약 편의성 제공

### 품질 목표
- Android / iOS 동일한 UI/UX 제공
- 오프라인 또는 API 오류 시 fallback 데이터로 앱 동작 유지
- flutter analyze 경고 0건 유지

---

| 가치 | 설명 |
|---|---|
| 접근성 | 외국인도 모국어로 사용 가능 |
| 단순함 | 3단계(검색→선택→확인)로 예약 완료 |
